AI Canvas —— 六种嵌入方式对照 QA

每个 Canvas 是同一份"职位预览" artifact,带唯一标签,便于判断 browser-bridge 读到了哪一个。

1) 内联同源 DOM (INLINE)

artifact 直接渲染进顶层文档。预期:完全可读可交互。

2) 同源 iframe · src (SAMEORIGIN_SRC)

<iframe src="artifact.html?label=SAMEORIGIN_SRC">。预期:#97 allFrames 可读。

3) srcdoc iframe (SRCDOC)

iframe.srcdoc 注入 HTML(预览最常见做法之一);URL 为 about:srcdoc,继承父源。

4) blob iframe (BLOB)

iframe.src = blob:… 由父页面生成的 HTML。

5) 跨源 iframe (CROSSORIGIN @ :8001)

<iframe src="http://localhost:8001/artifact.html?label=CROSSORIGIN">。预期:需授权该 origin 才可读。

6) 沙箱 iframe (SANDBOX, allow-scripts only)

sandbox="allow-scripts" → 不透明源(null origin)。预期:最难读。
